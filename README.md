# Madreseyar Teacher Android — 3.7.0 Mobile Upgrade

اپ Native معلم مدرسه‌یار با Jetpack Compose و ارتباط مستقیم با APIهای موجود در سورس فعلی هاست. هیچ WebView در اپ وجود ندارد و این نسخه به هیچ Patch جدیدی روی هاست وابسته نیست.

## اصلاح اصلی 3.6.1
نسخه 3.6.0 اشتباهاً چند مسیر `/api/staff/mobile/...` را فرض کرده بود و به همین دلیل روی هاست فعلی خطای «مسیر امنیت کارکنان پیدا نشد» می‌داد. در 3.6.1 همه این مسیرها حذف شده‌اند و پنج جریان کاری جدید فقط از APIهای واقعی موجود استفاده می‌کنند.

## پنج جریان کاری روزانه
- دانش‌آموزان من + عکس واقعی + پرونده آموزشی
- دفتر نمره حرفه‌ای مستمر/پایانی
- دفتر کلاسی با `/api/state` محدودشده معلم
- مرکز تکالیف + تحویل‌ها + تصحیح
- تصحیح سؤال‌به‌سؤال آزمون

## سرعت ورود
- گرفتن توکن، پایان ورود محسوب می‌شود و صفحه خانه فوراً باز می‌شود.
- Dashboard و Workspace به‌صورت موازی و در پس‌زمینه دریافت می‌شوند.
- بعد از اثر انگشت نیز صفحه خانه منتظر شبکه نمی‌ماند؛ اعتبار نشست در پس‌زمینه کنترل می‌شود.
- timeout شبکه: اتصال ۶ ثانیه، خواندن ۱۲ ثانیه.

## Build
Workflow آماده در `.github/workflows/build-apk.yml` از Gradle 8.9، Java 17 و Android 35 استفاده می‌کند.

## 3.6.2 — فیلتر کلاس/پایه
صفحه‌های «دانش‌آموزان من»، «گزارش‌ها» و «تحلیل دانش‌آموز» اکنون ابتدا کلاس/پایه معلم را با منوی کشویی انتخاب می‌کنند و سپس فقط دانش‌آموزان همان کلاس را نشان می‌دهند. گزارش و تحلیل نیز در صفحه جزئیات مستقل باز می‌شوند.

## 3.7.0 — ارتقای اپ موبایل معلم
- سؤال تصویری چهارگزینه‌ای در بانک سؤال با حفظ کلید تصحیح خودکار؛ تصویر در پیش‌نمایش.
- افزودن تصویر جدید در ویرایشگر سؤال از فایل گوشی.
- صفحه اصلی با خطای واضح، امکان تلاش مجدد و مدیریت انقضای نشست.
- خروج سریع، مدیریت صحیح خطای شبکه در ورود بیومتریک، دکمه Back و بهبود حافظه و امنیت.
- جزئیات کامل: `RELEASE-NOTES-3.7.0-MOBILE-UPGRADE-FA.md`.

## کارگاه طراحی آزمون ۳.۸.۰

- پیشنهاد متوازن سؤال از بانک تأییدشده، فیلتر فصل/نوع/دشواری و ویرایش قبل از افزودن.
- ورود گروهی سؤال از متن، بررسی کلید صحیح و بارم، حذف، جابه‌جایی و بازگرداندن حذف.
- توضیحات و محدودیت‌ها: `RELEASE-NOTES-3.8.0-EXAM-WORKSHOP-FA.md`.
